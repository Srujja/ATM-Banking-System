# ATM Banking System

A console-based ATM Banking System developed using Java. The application allows users to log in using a customer number and PIN and perform basic banking operations.

## Features

- Customer login using customer number and PIN
- Checking account management
- Savings account management
- View account balance
- Withdraw funds
- Deposit funds
- Input validation
- Menu-driven console interface

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- HashMap
- Scanner
- DecimalFormat

## Project Structure

ATM-Banking-System-Java
├── ATM.java

├── OptionMenu.java
└── README.md

## How to Run

1. Download or clone this repository.
2. Open the project in a Java IDE such as Eclipse, IntelliJ IDEA, or VS Code.
3. Compile the Java files.
4. Run `ATM.java`.
5. Enter a valid customer number and PIN.
6. Select the required banking operation from the menu.
